Diseñado para ingenieros de red

Todo lo que necesitas para generar comandos de enrutamiento listos para producción desde cualquier página web.

Sniffer de red

Captura solicitudes en segundo plano — AJAX, CDN, API — en tiempo real mediante Service Worker.

DNS Racing

En el modo «Auto (Racing - Fastest)» la consulta va a la vez a todos los proveedores DNS-over-HTTPS — Cloudflare, Google, Quad9, AdGuard y los tuyos — mediante Promise.any: se toma la primera respuesta correcta y se cancelan las demás. Si eliges un proveedor, solo se consulta ese. Las respuestas se guardan en caché.

Agregación CIDR

Fusiona IPs individuales en subredes optimizadas. Agregación IPv4 bitmask + IPv6 BigInt.

Optimización de rutas (RIPE BGP)

El prefijo BGP de cada IP, todos los prefijos de su AS o los prefijos del AS colapsados hasta un límite de rutas. Datos de RIPE Stat.

Consulta ASN

Resolución masiva IP-a-ASN. Ve qué organización posee cada IP: AS13335 (Cloudflare).

Exportación de archivos

Descarga como .bat, .sh, .rsc, .conf, .ovpn y más, con encabezados y comandos de verificación. El archivo lleva el nombre del sitio: example_com_route.bat.

Escaneo masivo

Pega una lista de URLs. Genera rutas agregadas para todos los hosts a la vez.

Lista negra de dominios

Excluye analítica, rastreadores y dominios no deseados. Se sincroniza entre dispositivos via Chrome Cloud Sync.

Funciona con DoH bloqueado

Si todos los resolvers DNS-over-HTTPS están bloqueados, usa las IPs a las que ya se conectó el navegador y resuelve el resto con el DNS del sistema.

Exportación Keenetic

El formato .bat de importación de Keenetic, con cada ruta comentada con sus dominios y ASN.

Los últimos 10 escaneos quedan en la extensión: ábrelos, cópialos o descarga las rutas como cryptocompare_com_route.bat.

Preguntas frecuentes

¿Qué plataformas soporta NetRoute?
NetRoute genera comandos de enrutamiento para 9 plataformas: Windows, Linux, macOS, MikroTik, Cisco, Juniper, WireGuard (AllowedIPs), OpenVPN y Keenetic, además de tu propia plantilla. Compatible con IPv4 e IPv6 (el formato Keenetic es solo IPv4).
¿NetRoute es gratis?
Sí, NetRoute es completamente gratis. No requiere registro ni suscripción.
¿Cómo genera NetRoute rutas desde un sitio web?
NetRoute descubre todos los dominios de una página web (incluyendo solicitudes AJAX, CDN y API mediante Service Worker) y los resuelve a direcciones IP por DNS-over-HTTPS: en el modo Auto la consulta va en paralelo a Cloudflare, Google, Quad9, AdGuard y tus servidores DoH y gana la primera respuesta correcta; con un proveedor elegido solo se consulta ese; las respuestas se guardan en caché y, si DoH está bloqueado, las IP se toman de las conexiones del propio navegador. Después agrega las IP en subredes CIDR optimizadas y genera comandos de enrutamiento específicos de la plataforma.
¿Se puede usar para VPN split tunneling?
Sí, NetRoute es ideal para enrutamiento selectivo VPN. Genera WireGuard AllowedIPs, directivas route de OpenVPN y comandos de enrutamiento del sistema que te permiten enrutar solo el tráfico de sitios específicos a través de tu VPN.
¿NetRoute recopila datos personales?
No. NetRoute no tiene cuentas, analítica ni servidores propios: la configuración, la caché y el historial de escaneos se quedan en tu navegador. Para funcionar envía los dominios escaneados a resolvers DNS-over-HTTPS, consulta el ASN de las IPs resueltas en ip-api.com, consulta RIPE Stat cuando la optimización de rutas está activa y se conecta directamente a los sitios escaneados si DoH está bloqueado o la comprobación de ping está activada. Los detalles están en la política de privacidad.
