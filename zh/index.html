智能路由 生成器

发现网页上的每个域名。解析为IP。

// 功能特性

专为网络工程师打造

从任何网页生成生产级路由命令所需的一切。

网络嗅探器

通过Service Worker实时捕获后台请求 — AJAX、CDN、API调用。

DNS竞速

在「Auto (Racing - Fastest)」模式下，查询通过 Promise.any 同时发往所有 DNS-over-HTTPS 提供商——Cloudflare、Google、Quad9、AdGuard 和你自己的服务器——取第一个成功的响应，其余请求取消。选定某一提供商时只查询它。结果会被缓存。

CIDR聚合

将单个IP合并为优化的子网。IPv4位掩码 + IPv6 BigInt聚合。

路由优化（RIPE BGP）

每个IP的BGP前缀、其AS公告的全部前缀，或压缩到路由数量限制内的AS前缀。数据来自RIPE Stat。

ASN查询

批量IP转ASN解析。查看每个IP的所属组织：AS13335 (Cloudflare)。

文件导出

下载为.bat、.sh、.rsc、.conf、.ovpn等格式，包含文件头和验证命令。文件以网站命名：example_com_route.bat。

批量扫描

粘贴URL列表。一次性为所有主机名生成聚合路由。

域名黑名单

排除分析、追踪器和不需要的域名。通过Chrome Cloud Sync跨设备同步。

DoH被封锁时仍可用

当所有DNS-over-HTTPS解析器都被封锁时，改用浏览器已连接的IP，其余通过系统解析器解析。

Keenetic导出

Keenetic导入用的.bat格式，每条路由附带其域名和ASN注释。

代理客户端规则

同样的域名和网段以规则形式输出：sing-box（Hiddify）、Clash/mihomo、Xray 和 3X-UI、v2rayN、Happ、Shadowrocket/Surge、Quantumult X、PAC，以及 AmneziaVPN 的站点列表。

路由器列表

用 MikroTik address-list 和 Keenetic DNS 路由（KeeneticOS 5）代替数百条路由；通过 uci 写入 OpenWrt 的持久路由。

扫描历史

扩展保留最近10次扫描：随时打开、复制或将路由下载为cryptocompare_com_route.bat。

自定义模板

使用{{network}}、{{cidr}}、{{gateway}}等宏定义自己的路由语法。

// 指南

热门配置指南

每个支持平台的分步教程 — 命令语法、官方文档链接和可编辑的配置示例。

Keenetic — .bat 上传

在 NetRoute 中生成 .bat 文件，上传到 Keenetic 并绑定 VPN 接口。

MikroTik — .rsc 导入

RouterOS 脚本，使用 /ip route 命令。一次 /import 应用所有路由。

WireGuard — AllowedIPs

通过对等配置中的 AllowedIPs 实现分流。无需额外的路由命令。

Linux — ip route

ip route add shell 脚本。通过 systemd-networkd 或 NetworkManager 实现持久化。

OpenVPN — route 指令

将 route 行追加到客户端 .ovpn。配合 route-nopull。

sing-box — rule-set

网站的域名和网段生成 sing-box 与 Hiddify 的 rule-set：route.rule_set，编译为 .srs。

Happ — 路由配置文件

包含 ProxySites 和 ProxyIp 列表的 JSON 配置；通过 happ://routing/onadd 链接导入应用。

Xray — routing.rules

用于 Xray-core 配置、3X-UI 面板以及导入 v2rayN 的规则。

AmneziaVPN — 站点列表

带地址的主机和子网，用于分流；通过 ⋮ 菜单导入。
// 常见问题

常见问题

NetRoute 支持哪些平台？
NetRoute 输出 21 种格式。操作系统和路由器的路由命令：Windows、Linux、macOS、OpenWrt、MikroTik、Cisco、Juniper、Keenetic；VPN 和代理客户端的规则：WireGuard（AllowedIPs）、OpenVPN、AmneziaVPN、sing-box、Clash/mihomo、Xray、v2rayN、Happ、Shadowrocket/Surge、Quantumult X 和 PAC；路由器列表：MikroTik address-list 和 Keenetic DNS 路由（KeeneticOS 5）。另支持自定义模板。支持 IPv4 和 IPv6；Keenetic .bat、AmneziaVPN 和 PAC 格式仅支持 IPv4。
NetRoute 是免费的吗？
是的，NetRoute 完全免费。无需注册或订阅。
NetRoute 如何从网站生成路由？
NetRoute 发现网页上的所有域名（包括通过 Service Worker 的 AJAX、CDN 和 API 请求），并通过 DNS-over-HTTPS 将其解析为 IP 地址：Auto 模式下并行查询 Cloudflare、Google、Quad9、AdGuard 和自定义 DoH 服务器，第一个成功的响应获胜；选定某一提供商时只查询它；结果会被缓存，DoH 被封锁时改用浏览器自身连接中的 IP。随后将 IP 聚合为优化的 CIDR 子网，并生成特定于平台的路由命令。
NetRoute 能用于 Hiddify、Happ、v2rayN 等代理客户端吗？
可以。在「目标系统」中选择客户端的格式，NetRoute 会输出包含网站域名和网段的规则，而不是路由命令：sing-box（Hiddify、NekoBox）的 rule-set、Clash/mihomo 的 rule-provider、Xray 和 3X-UI 面板的 routing.rules、v2rayN 的规则导入文件、Happ 路由配置文件、Shadowrocket/Surge 和 Quantumult X 的规则列表、PAC 文件以及 AmneziaVPN 的站点列表。域名按后缀合并；网段与路由中的相同。
可以用于 VPN 分流吗？
可以，NetRoute 非常适合 VPN 分流。它生成 WireGuard AllowedIPs、OpenVPN 路由指令和操作系统级路由命令，让您仅将特定网站的流量通过 VPN 路由。
NetRoute 会收集个人数据吗？
不会。NetRoute 没有账户、分析或自己的服务器：设置、缓存和扫描历史都保存在您的浏览器中。为完成工作，它会把扫描到的域名发送给 DNS-over-HTTPS 解析器，通过 ip-api.com 查询已解析 IP 的 ASN，在启用路由优化时查询 RIPE Stat，并在 DoH 被封锁或启用 ping 检查时直接连接被扫描的网站。详情见隐私政策。
