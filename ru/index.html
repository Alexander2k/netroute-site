Умная генерация маршрутов

Находит все домены на странице. Резолвит в IP.
Генерирует маршруты и правила для 21 формата мгновенно: роутеры, ОС, VPN- и прокси-клиенты.

Установить из Chrome Web Store
example_com_route.sh 
#!/bin/bash
# NetRoute v4.1.3 — generated 2026-10-17

ip route add 104.21.32.0/24 via 10.0.0.1
ip route add 172.67.182.0/24 via 10.0.0.1
ip route add 151.101.1.0/24 via 10.0.0.1
ip -6 route add 2606:4700::/32 via fe80::1 dev wg0

# Verify: ip route show | grep "10.0.0.1"

Создано для сетевых инженеров

Всё, что нужно для генерации production-ready команд маршрутизации с любой веб-страницы.

Сетевой сниффер

Перехватывает фоновые запросы — AJAX, CDN, API — в реальном времени через Service Worker.

DNS Racing

Запрашивает Cloudflare, Google, Quad9 и AdGuard одновременно через Promise.any. Побеждает первый ответ. Можно добавить свои DoH-серверы.

CIDR агрегация

Объединяет отдельные IP в оптимизированные подсети. IPv4 bitmask + IPv6 BigInt агрегация.

Оптимизация маршрутов (RIPE BGP)

BGP-префикс каждого IP, все префиксы его AS или префиксы AS, сжатые до лимита маршрутов. Данные из RIPE Stat.

ASN поиск

Пакетное определение IP-to-ASN. Узнайте, какой организации принадлежит каждый IP: AS13335 (Cloudflare).

Экспорт файлов

Скачивайте как .bat, .sh, .rsc, .conf, .ovpn и другие, с заголовками и командами проверки. Файл называется по сайту: example_com_route.bat.

Массовое сканирование

Вставьте список URL. Сгенерируйте агрегированные маршруты для всех хостов сразу.

Чёрный список доменов

Исключайте аналитику, трекеры и ненужные домены. Синхронизация между устройствами через Chrome Cloud Sync.

Работает при блокировке DoH

Если все DNS-over-HTTPS серверы заблокированы, берёт IP из соединений самого браузера, а остальное резолвит через системный DNS.

Экспорт для Keenetic

Формат .bat для импорта в Keenetic: у каждого маршрута комментарий с доменами и ASN.

Правила для прокси-клиентов

Те же домены и сети как правила: sing-box (Hiddify), Clash/mihomo, Xray и 3X-UI, v2rayN, Happ, Shadowrocket/Surge, Quantumult X, PAC — и список сайтов для AmneziaVPN.

Списки для роутеров

MikroTik address-list и DNS-маршруты Keenetic (KeeneticOS 5) вместо сотен маршрутов; постоянные маршруты OpenWrt через uci.

Популярные инструкции

Пошаговые руководства для каждой поддерживаемой платформы — синтаксис команд, ссылки на официальную документацию и готовые примеры конфигов.

Keenetic — загрузка .bat

Сгенерируйте .bat в NetRoute и загрузите на Keenetic с привязкой к VPN-интерфейсу.

MikroTik — импорт .rsc

RouterOS-скрипт с командами /ip route. Один /import применяет все маршруты.

WireGuard — AllowedIPs

Split tunneling через AllowedIPs в конфиге пира. Без дополнительных команд маршрутизации.

Linux — ip route

Shell-скрипт с ip route add. Постоянство через systemd-networkd или NetworkManager.

OpenVPN — route

Добавьте директивы route в клиентский .ovpn. С route-nopull.

sing-box — rule-set

Домены и сети сайта как rule-set для sing-box и Hiddify: route.rule_set, компиляция в .srs.

Happ — профиль маршрутизации

JSON-профиль со списками ProxySites и ProxyIp; в приложение — ссылкой happ://routing/onadd.

Xray — routing.rules

Правила для конфига Xray-core, панели 3X-UI и импорта в v2rayN.

AmneziaVPN — список сайтов

Хосты с адресами и подсети для раздельного туннелирования, импорт через меню ⋮.

Частые вопросы

Какие платформы поддерживает NetRoute?
NetRoute выдаёт 21 формат. Команды маршрутов для систем и роутеров: Windows, Linux, macOS, OpenWrt, MikroTik, Cisco, Juniper, Keenetic; правила для VPN- и прокси-клиентов: WireGuard (AllowedIPs), OpenVPN, AmneziaVPN, sing-box, Clash/mihomo, Xray, v2rayN, Happ, Shadowrocket/Surge, Quantumult X и PAC; списки для роутеров: MikroTik address-list и DNS-маршруты Keenetic (KeeneticOS 5). Плюс свой шаблон. Поддерживаются IPv4 и IPv6; форматы Keenetic .bat, AmneziaVPN и PAC — только IPv4.
NetRoute бесплатный?
Да, NetRoute полностью бесплатен. Не требуется регистрация или подписка.
Как NetRoute генерирует маршруты с сайта?
Расширение находит все домены на веб-странице (включая AJAX, CDN и API запросы через Service Worker), резолвит их в IP-адреса параллельными DNS-over-HTTPS запросами к Cloudflare, Google, Quad9 и AdGuard (если DoH заблокирован — берёт IP из соединений самого браузера), агрегирует IP в оптимизированные CIDR-подсети и генерирует команды маршрутизации для выбранной платформы.
Подходит ли NetRoute для прокси-клиентов — Hiddify, Happ, v2rayN?
Да. Выберите формат клиента в списке «Целевая ОС», и вместо команд маршрутов NetRoute выдаст правила с доменами и сетями сайта: rule-set для sing-box (Hiddify, NekoBox), rule-provider для Clash/mihomo, routing.rules для Xray и панели 3X-UI, файл импорта правил для v2rayN, профиль маршрутизации Happ, список правил для Shadowrocket/Surge и Quantumult X, PAC-файл и список сайтов для AmneziaVPN. Домены сворачиваются по суффиксам, сети — те же, что в маршрутах.
Можно ли использовать для VPN split tunneling?
Да, NetRoute идеально подходит для выборочной маршрутизации VPN. Расширение генерирует WireGuard AllowedIPs, OpenVPN route-директивы и команды ОС, чтобы через VPN шёл трафик только определённых сайтов.
Собирает ли NetRoute персональные данные?
Нет. У NetRoute нет аккаунтов, аналитики и своих серверов: настройки, кеш и история сканов хранятся в браузере. Для работы расширение отправляет найденные домены DNS-over-HTTPS серверам, узнаёт ASN найденных IP через ip-api.com, обращается к RIPE Stat при включённой оптимизации маршрутов и подключается к самим сканируемым сайтам, если DoH заблокирован или включена проверка доступности. Подробности — в политике конфиденциальности.
